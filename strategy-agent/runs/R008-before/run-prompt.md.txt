# 一轮研究提示模板

按本目录 AGENTS.md 执行。

- 待决问题：D001 北美增长修复，或用户明确指定的问题。
- 新输入：填写文件路径、网址或访谈记录；没有新输入时先读取当前缺口。
- 时间口径：案例基准 2026-10-08；补充资料另列实际日期。
- 优先动作：只研究可能改变选项排序的关键未知。
- 输出：更新证据台账、假设清单、决策卡、dashboard，新增不可覆盖的 R 编号记录。
- 汇报：当前建议、发生变化的证据、仍无法判断的部分、下一步。

禁止把用户偏好的 wearable fashion 当作既定结论。必须比较核心产品更新、现有日常产品的呈现改善、日常场景产品试点，以及保持现有组合的选择。
