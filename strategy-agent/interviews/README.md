# D001 访谈工具包

2026-11-07，v1.0；关联R003。仅供访谈员和记录员使用，不把原因标签页或本表当问卷发给受访者。

- [访谈提纲](访谈提纲.docx)：4页，30–35分钟。事件A为最近一次真实考虑购买，事件B为可选对照；先品类经历，后具体品牌；无近期经历有跳转。
- [单人记录表](单人访谈记录表.docx)：3页，每人复制一份；前2页现场记录，第3页访后分析。背景中的品牌项目在品牌模块后补填，不按表格从上到下提前问品牌。

先做2次试访。原话、意译、事实自述、假设意向和研究者解释分开；S自发/N中性追问/C提示后/I推断。可多原因共存，也允许信息不足，不能将没提到记作没有。

记录按访谈日期进入当前研究，不作为2026-10-08案例当时已知事实。与原同学访谈分开编号，不把工具包或空表写入消费者证据台账。实际研究后再建立逐条证据与H编号映射。

保存填写版本可命名 `INT001_日期.docx`，使用匿名编号；不要覆盖空白模板。模板为普通可编辑Word，不是自动数据库或交互式表单。手写空间不够时附页并标受访者/事件编号。

内容源于D001与研究计划，本轮没有新增消费者证据，未改变战略推荐。生成脚本用于维护，修改后需重新渲染并检查排版。
