# R029 上市日历长度：lululemon与其他品牌

2026-11-19。问题：E059访谈称规划已到2028年夏季，其他品牌的规划与开发周期是否同样长。可能改变的选择：D002近期与远期的分界，以及“周期长”是公司特有约束还是行业常态。

## 2. 能说和不能说的

能说：
- lululemon管理层公开承认上市日历约18–24个月，并把缩短到12–14个月作为目标。这与E059访谈中“规划已到2028年夏季”的说法相容，且属案例前的公开表述，使D002的时间分界不再只依赖访谈。
- 长周期并非lululemon独有：EY案例中的多品牌服饰公司为18–20个月。
- 行业内存在明显更快的做法：EY认为约40周可行；一家直营运动服饰品牌在2017年被报道为三个月。

不能说：
- 不能说lululemon比主要竞品慢。Alo和Vuori没有公开数字，Gymshark的数字过旧且口径不明。
- 不能把“上市日历”“开发周期”“设计到上市”“规划范围”当作同一口径比较。规划团队在做2028年夏季，不等于每件产品都需要这么长的开发时间。
- 不能说缩短周期会带来多少收入。管理层的12–14个月是预期，不是已实现结果。

## 3. 对D002近期与远期分界的含义

- 分界现在有一条公开依据（来源1）和一条访谈依据（E059），方向一致。
- 来源1未区分核心款、核心季节款与季节款。R028把“季节款与配色选品”列为近期，所依据的2–12周和约半年是在架销售时间，不是开发时间，该处已在D002更正。
- 若管理层的缩短目标实现，远期动作的见效时间会提前；这是公司现行计划的一部分，不是本研究的新增建议。
