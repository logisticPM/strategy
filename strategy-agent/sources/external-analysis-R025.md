## 2. 各来源的内容与口径

### 2.1 Consumer Edge直营渠道份额（来源1）

- 口径：八个品牌直营渠道之间的份额，品牌为lululemon、Nike、Adidas、On、Alo Yoga、Vuori、Under Armour、Deckers。不是整体市场份额。地区、是否仅美国、是否卡交易面板，文章均未说明。
- 数字：lululemon 2025年1月30%，9月和10月27%，11月24%。Alo Yoga 9月8%、10月12%、11月14%。Vuori 11月5%，全年大致持平。
- 同文转述时任CEO 2025年9月的公开说法：核心品类生命周期拉得过长，休闲产品过于可预测；美国高端运动服饰市场仍在下滑；计划把新款占比从23%提高到约35%。另有分析师称已增加新款但顾客反应不及预期。
- 限制：Alo三个月上升6个百分点，波动大；11月是促销季，月度份额可能受促销档期影响，这是本轮推断，文章未作此解释。

### 2.2 Circana品类数据与分析师观点（来源2）

- Circana，美国运动服饰，2025年年初至今（具体月份未给）：金额同比+3%，件数+7%；其余服饰市场−4%（未说明金额或件数）。
- Euromonitor：全球运动服饰2020年以来逐年增长，2025年预计增近5%。
- 文章自注：两套数据都不单列高端运动服饰。
- 观点（均为具名评论人意见，无数据）：产品可预测、失去差异点；Alo和Vuori势头上升；一位顾问称部分健身人群从紧身裤转向宽松款，并称公司对紧身裤放缓反应慢；另有分析师认为品牌与品类两方面原因都有。投行观点提到7月降价幅度及核心黑色紧身裤出现在奥莱。
- 本轮推算：件数增速高于金额增速，意味着平均单价下降。文章未作此表述。

### 2.3 Piper Sandler青少年调查（来源3，案例后）

- 约9,000名13至19岁青少年；调查期与地区未说明。
- lululemon心智份额连续第五次调查下降，高收入女孩中尤其明显。未给出名次或百分比。
- 运动品牌（含Nike、Adidas、lululemon）在青少年时尚中的份额为29%，上年32%，三年前44%；该数字出自Piper Sandler的社媒帖，经文章转引。
- 青少年总支出同比+6%，服饰+7%，女孩服饰+10%，鞋类−1%。Alo Yoga被列为女孩中受欢迎的运动服饰品牌。

### 2.4 Advan客流与转化估算（来源4）

- 针对FY2024 Q4：Advan估计单店客流+4%，被转化率和店均客单价下降抵消。随后一季至当时，估计客流放缓280个基点，转化率进一步走弱。
- 判断：宏观没有恶化，实体店竞争（Alo、Vuori）也未加剧；问题更可能是款式与“价值感知”。引用美国BEA个人消费数据：2025年2月女装增长3.5%。
- 洛杉矶地区对比：2023年12月至2025年1月，Vuori到访量为1.1倍，lululemon为1.05倍；lululemon基数大，绝对增量更多。
- 转述管理层当时的说法：新客获取与留存指标仍强，机会在提高每位顾客的收入。
- 限制：2025年初的情况；数字为该公司自有估算，方法未披露。

### 2.5 2026年9月的评论文章（来源5、6）

- 三位外部评论人（来源5）：产品乏味、非核心产品过多、缺少有意义的技术创新、价格被视为对平庸产品的溢价；国际增长此前掩盖了核心市场下滑。均为意见。
- 晨星分析师（来源6）：估计运动休闲市场每年增长约3%–5%，无数据集；认为疫情期间囤货导致当前需求不足。
- 两文中的公司数字均转述Q2公告，见第3节核对。

## 3. 媒体数字与台账官方数字核对

核对对象是台账E001、E039、E046及[R014八季表](operating-sequence-R014.md)中2026-11-07已核查的官方Q2公告数字；本轮未重读公告原文。

| 媒体说法 | 台账官方数字 | 结论 |
|---|---|---|
| Q2净收入同比−4%（来源5） | 全球收入−4% | 一致 |
| 可比销售−9%，未标地区（来源5） | 全球可比−9%（固定汇率−10%） | 一致，为全球口径 |
| “美国可比销售−12%”（来源5） | 美洲可比−12%；公告地区表不单列美国可比 | 数字一致，地区标注有误，应为美洲 |
| 美洲收入Q1 −3%、Q2 −8%（来源5） | 美洲收入Q1 −3%、Q2 −8% | 一致 |
| 国际可比销售本季转负（来源5） | 国际可比−3%（固定汇率−6%） | 一致 |
| “上季销售下降9%”（来源6） | 收入−4%，可比−9% | 表述不精确，指的是可比销售 |
| 会前准备稿：上半年公司收入大致持平 | 全球收入Q1 +4%、Q2 −4% | 大致成立，为近似表述 |

访谈中“库存件数未增而成本上升”的说法，与R014记录的Q2库存金额−1%、件数−7%方向相容。R014另记Q2毛利率含1.345亿美元关税退款，引用关税压力时需一并说明。

## 5. 对访谈内部视角的对照

- 公司特有因素：直营份额下降（2.1）和运动服饰品类仍增长（2.2）指向下滑不全是宏观；但高端层没有单列数据，时任CEO也公开称高端市场在下滑。
- 竞品：访谈称不跟随竞品；2.1显示Alo份额在促销季快速上升。是否由促销驱动未知。
- 产品：管理层2025年9月已公开承认产品可预测、生命周期过长；访谈把创新流程描述为优势。两者时点不同，不必然矛盾。
- 客流与客单价：访谈称客流下降、客单价持稳；2.4在2025年初估计客流上升、转化率与客单价下降。时期不同，不能直接对比。
- 年轻客群：2.3提供了访谈中“想吸引年轻顾客”的外部背景，但属案例后信息。
