# 全品类产品地图与wearable fashion研究边界

日期2026-11-07。状态：研究设计与分析推断，不是已完成的全产品档案或商业方案。依据E007/E012/E022/E027–E038。用户最新要求纳入全品类档案思路；不自动执行无限广泛采集。访谈继续后置。

## 两层档案

第一层覆盖全品类：地区→性别/产品适用人群→品类→产品家族→版本→SKU（尺码颜色）。活动/场景为多对多标签，office wear是场景而非与裤装并列的独立品类，避免重复统计。完整覆盖只能在明确国家、渠道、读取日与官方分类目录下宣称，不能凭搜索发现量声称覆盖率。

基础字段：官方名称/链接、所属家族、主场景与功能主张、面料及可核技术说明、版型、长度与尺码范围、标价/促销/币种/采集时间、在售/缺码快照、历史版本、来源状态。US/CA分开；挂牌价非成交价，某日缺码非长期供给缺口，评论量/热销标签非销量。

第二层按决策价值深挖：顾客任务、选择链、具体版本、购买/试穿/退货、穿用场景、正反体验、价格渠道、替代品牌及替代类型、服务最终结果、未满足需求及反证、所关联H/D/E编号。公司主张、顾客自述、测试结果和我们的推断分栏。一个顾客事件去重，同串标家族；不把多标签相加成原因占比。

外部市场与消费者证据不能只从品牌粉丝社群获取：官方商品/退换规则、商品评价、运动/通勤/旅行社群、竞品比较、独立实测分别记录；营销/赠品/联盟披露作来源标签。原价/折扣/二手分开，存续偏差、抱怨偏差与换代混杂明确标注。未知收入/地区不推断。

## 深挖排序（研究优先级，非市场规模判断）

| 层次 | 对象 | 需要改变的选择 |
|---|---|---|
| 第一批 | 女装日常长裤（Daydrift等已有家族为入口） | 真实版型缺口还是选款/库存/呈现；决定A/B及C |
| 第一批对照 | 女装核心leggings与训练下装（Align/Wunder Train等） | 新日常购买是新增、抢回竞品还是挪走原本核心购买；保留功能护栏 |
| 第二批 | 女装日常上衣/轻外搭；男装日常裤/上衣 | 上下装搭配、结构与轮廓是否确有缺口；男装单独验证，不由女装外推 |
| 轻地图后按触发升级 | 鞋、包、配饰及跑步/网球/户外相关产品 | 先定位品类和场景交叉；出现具体独立事件、重大经济性或产品风险才加深 |

优先顺序取决于：是否能改变D001、与经营问题的关联、证据缺口、可核性和验证成本。不能因评论多就判业务最重要；全品类收入/贡献数据缺失时明确写未知，不给虚构分数。每轮有截止时间与固定问题，若新增材料只重复同主题、不能改变选择，停止扩量。

## wearable fashion具体化（待验证的产品方向）

工作定义：将技术舒适、活动自由与耐用体验，做成适合目标顾客日常场景、愿意反复穿且容易搭配的轮廓和细节。品牌契合由E022支持，独特性/支付意愿/利润未证。不能只把“好看”当可测定义。

优先顾客：已有Lulu购买/穿用经验、仍有相关衣着预算与近期购买任务，却因具体款式或合身放弃某产品，或将这笔预算给其他品牌的人；按行为筛选，不武断固定年龄、收入或职业。保留满意/正价购买者对照；衣橱已足够且没有新任务者不作为第一批拉动对象，但用“不买”选项检验机会是否虚假。预算受限、缺陷/客服主导者另轨分析，不能先假定设计解决。

第一场景：允许smart casual的混合办公及通勤，久坐、走动、下班非正式社交；旅行与周末出行作第二场景。正式西装办公室、晚礼服、高强度运动全兼容暂不承诺。R04旅行穿用/R05加购支持已有需求，R06/R07相反合身体验说明需分体型；北美市场规模仍未知。

首要品类：女装已有日常裤的适配优化，而非从零开office wear线。潜在要解决的是腰高/裆部比例与身体不合、轮廓不符合场合，具体问题仅有个案，不是全线缺陷。第二品类为易搭配上衣/轻外搭，测试非露腰、合适衣长、轻而有形等设计变量；这些是从R08/R17推导的待验证设计命题，并未证明现有目录不存在。男装作为独立第二波，不与女装偏好混算。

建议概念只做一条现有裤的针对性改进，以及与之配合的上衣/外搭展示；先用现有产品搭配，不默认新增三个SKU。选款和搭配即可解决则优先B；经正确选码仍失败才推进A；确有现有家族无法满足的任务且利润成立才推进C。

## 支持方向所需证据与否决条件

1. 任务确实存在：明确US/CA、最近一次具体场合、实际已有衣服及实际替代交易；不是问“你喜不喜欢这个理念”。初期公开数据缺这些字段就标未知，之后再访谈，不立即外发。
2. 现有产品未解决：让最合适的现款、正确尺码/长度、正常库存与清晰搭配说明先作为对照。目录已覆盖但不知晓/缺码→B；仍试穿失败→A；全新任务→C候选。
3. 设计增量而非降价：同价比较现款、改版、真实竞品与“不买”；同图文质量/轮换展示，单独改设计或呈现。先别用新文案+新模特+降价一起制造偏好。
4. 实穿胜过图片：久坐/行走舒适、遮挡与贴身问题、轮廓保持、洗后尺寸/起球等按场景测。口袋、防皱等未被顾客提出前只是待测功能，不擅称已发现需求。
5. 正价行为与品牌契合：概念喜欢之后需实际购买/保留、退货原因、与现款及竞品比较；观察技术舒适认知有无削弱。公司使命契合是必要条件，不是收益证据。
6. 净增量：追踪是否原本会买同品牌核心或另一日常款，扣蚕食、退货、开发、营销/履约与库存成本。增量贡献应为正，质量/退货与核心正价表现不恶化；幅度和样本量按基线波动/经济性预先设定，不编造百分比。

否决/转向：呈现改善已足够→不做新品；没有新任务且“不买”稳定胜出→不靠上新刺激饱和衣橱；只有降价才能成交→重新做价值/成本判断；实穿或洗后劣于现款→停止放量；仅蚕食自身销售→不将新品销售当增长。

现阶段结论：支持做有限概念与产品适配研究，尚不支持大规模时尚转型。全品类基础地图是约束方案的必要背景，不是先做完全量SKU深研才允许提出假设。
